# Frozen original regional scene evidence

`scenes.py` generates local CC0 scene metadata and PNG images from pinned official OFL fonts. Code follows the repository license. Fonts are verified locally and never included in scene output. There is no private source, model inference, GPU use or production activation. Vocabulary/font sharing and finite authored grammar limitations are explicit.

Run `python -m tools.RegionKaomoji.scenes generate --dataset <fresh artifacts directory> --fonts <local fonts.json>` or `validate --dataset <existing directory>`. Generation creates development and heldout files before any CPU model evaluation. Heldout inference requires the evaluator's frozen model/router/fusion selection and first-use receipt; scene validation itself verifies truth during generation without performing model evaluation.

## Files and coordinates

`dataset.json` uses `localocr.region-scenes.v1`, `synthetic_only:true`, original CC0 provenance, renderer/font dependencies, exact grammar expressions, seed and split `{file,sha256,count,requested}`. `freeze.json` uses `localocr.region-scenes.freeze.v1` with dataset and split SHA-256 and scene/face counts. `heldout-seal.json` binds those hashes and records that no inference result has been seen. `generation.json` gives counts, exclusions, bytes, elapsed time and actual CPU-only generation status. No file should be overwritten after freeze.

A split is a JSON list. Each row has `id`, `split`, `source_split`, `scene_kind`, `recipe_family` (SHA of actual layout expression), `text`, `text_sha256`, relative `image`, `sha256`, `pixel_sha256`, `width`, `height`, `regions`, `provenance` and a statement that baseline omission is unmeasured. Pixel SHA binds original dimensions and decoded RGB bytes, rather than PNG container metadata. Source split is this new whole-scene split; it does not map to or read the pretrained crop heldout.

Each region has `id`, `kind` (`body`, `kaomoji`, `graphic`), exact `text`, `span`, `bbox`, `font_ids`, `rendering`, relative `mask`, `mask_sha256`, and `pixel_count`. Text regions additionally record font size and applied contrast. `bbox` is original-image `[left,top,right,bottom)`, obtained from the nonzero actual visible-ink mask, not a predicted or per-character box. A mask is an original-sized binary L PNG: nonzero values represent every visible raster pixel belonging to that region, including punctuation and arms. Region masks are disjoint and their union equals all visible source ink on positive scenes. Blank gradients are background without text masks. `span` uses raw Python Unicode codepoint `[start,end)` indices into the row reading-order string; graphics use null. No normalization, score interpretation or character box fabrication occurs.

Reading-order chunks on one line are joined by two literal U+0020 spaces; lines by LF. Horizontal placement retains shaped glyph advances, with a declared 18-pixel layout gap between chunks; that layout gap is not a claim of universal font-space metric or arbitrary screenshot whitespace recoverability. Actual region `text` is what the raster renderer receives. The regional evaluator should assess exact regional strings and alignment, not infer individual character positions from this layout metadata.

## Truth must stay out of inference

Candidate discovery receives only image pixels and the actual first-pass OCR output. Neither `regions`, label spans, masks nor expected face text may construct or select inference candidates. Only the metrics stage loads truth. Crop completeness can be measured as the fraction of a kaomoji's mask pixels inside an automatically proposed box, including all terminal marks; body swallowing as intersecting body mask pixels or body boxes. A padded candidate with 100% face-mask coverage can still fail if it also contains body glyphs. No detection recall threshold is implied by the fixture.

Ten scene categories include same-line and separate-line body/face layouts, middle faces, low-contrast body, small or faint face stress, ordinary bracketed sentences, text with graphics, graphics only and blank. Dev/heldout whole layout families, nonempty scene and regional text hashes, and decoded scene pixels are mutually exclusive. Fonts and vocabulary primitives are shared. Small/faint faces only make first-pass omission plausible: actual omission is counted after real baseline CPU evaluation, never asserted by the generator. Partial attempts remain historical artifacts and are not the final scale dataset.

## Tight tracking (card generator v3, grammar generator v2)

Real UI fonts place neighbouring glyphs so close that antialiasing halos touch. Card scenes `localocr.card-scenes.20261015.v3` and grammar scenes `localocr.grammar-scenes.20261015.v2` keep every earlier layout family and render half of the text segments (probability 0.5, chosen independently per segment) with a glyph-advance delta of -1 or -2 pixels. Tracking is a layout parameter of the renderer, not an ink effect: glyph bitmaps, effects and masks are unchanged, every mask still equals the visible ink of its segment, and the value is recorded in the region's `rendering.tracking` (absent means 0). Dataset metadata declares the tracking recipe; earlier generator ids validate exactly as before.
