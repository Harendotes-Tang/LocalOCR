# 颜文字专项 OCR 测评记录（2026-10-11）

本次完成合成数据训练、冻结候选和独立测评。候选改善了保留合成集上的颜文字识别，但普通文字与真实负样本出现退化，且缺少可唯一标注的真实颜文字精确结果，因此未达到接入标准。应用继续使用当前固定 OCR；专项候选、训练依赖和私人验证材料均未进入生产运行时。

## 测评范围与方法

对当前固定 PP-OCRv6 small 识别模型与候选模型使用同一张裁片，比较未经生产修正的识别结果。本报告测量识别器的裁片识别能力，不代表完整应用的自动区域定位、符号复读、Qt 解析或预览导入准确率。

整串正确要求原始 Unicode 码点和空格全部一致。字符错误率（CER）按编辑距离计算，数值越低越好；符号 CER 单独计算符号序列。没有可靠精确标签时不计算准确率，不将缺少证据记为零错误。候选仅按开发集整串正确数选择，选择后冻结模型、字符表、数据清单与图像哈希，再测保留测试及私人裁片。独立结果未用于后续调参。

## 数据与训练

根据用户指定的 [LDDGO 颜文字页](https://www.lddgo.net/common/emoticons)，本地解析得到 485 个条目、385 个精确去重文本。其中 1 个预留验证文本和 7 个无法完整渲染的文本被排除。新增语料实际渲染后的训练、开发、测试独立文本数为 262、37、74；70/10/20 是渲染前分配比例，不能据此宣称渲染后比例完全相同。来源 HTML 与提取语料保留在本地忽略目录，不作为开放许可数据集发布。

最终数据共 12,610 张训练图、299 张开发图和 564 张保留测试图。非空文本集合互不重叠；用户提供的 3 条原文从所有分割排除。扩充时保留原有文本的分割归属，原保留测试中的 461 个文本保留了 458 个，另外 3 个因字体渲染检查被排除。字库包含 402 个字符，训练图覆盖 398 个，仍有 4 个字符缺少训练实例。测试采用保留主字体，但稀有字形后备字体仍有共享；字体与游戏截图的差异尚未消除。

模型为 CNN + 双向 GRU + CTC 序列识别器，共 345,939 个参数。实际在 NVIDIA GeForce RTX 5070 Laptop GPU 上使用 CUDA 12.8、PyTorch 2.10.0 训练 128 轮，batch 96、学习率 0.001、种子 20261011。训练、导出与等价验证合计约 8 分 44 秒；首个最优开发结果出现在第 114 轮（211/299）。训练峰值张量分配约 689 MiB，不包含驱动及完整 GPU 进程占用。ONNX 为 1,390,444 字节（约 1.33 MiB）；12 个开发样本的 PyTorch CPU 与 ONNX CPU 解码结果一致。

## 本地真实裁片验证

两张用户截图共提取 26 个手工裁片，仅用于专项模型独立验证：4 个颜文字、14 个普通文字及 8 个空白或图标负样本。截图此前已用于通用 OCR 验证，不能称为整个应用从未见过的测试材料。

4 个颜文字无法从截图唯一确定完整码点，均从整串和 CER 指标排除，因此没有可证明的真实颜文字精确改善。14 个可靠普通文字裁片在基线中全部正确，候选全部出现错误。8 个真实负样本中，候选在 2 个图标裁片输出了文字。可确认的单字形特征共 3 项，基线包含 2 项、候选包含 1 项；字符包含检查不能证明重音、横线的位置或数量正确。

用户另外提供的 3 条原文不对应上述真实颜文字裁片。将原文使用 3 种保留主字体合成渲染后，得到 9 个补充样本，整串正确数为基线 0/9、候选 1/9；该结果属于合成验证，不能替代真实截图精确验证。

## Emoji 补充检查

另外渲染了 6 个常见 emoji 字符或组合序列，覆盖表情、手势、带变体选择符的符号、旗帜和 ZWJ 家庭组合，使用本机 Segoe UI Emoji 彩色字体。基线和候选的整串正确数均为 0/6。因此当前不能承诺 emoji 完整识别。

字典检查中，基线能表达其中 3/6 个完整序列，专项候选为 0/6。字典能够表达不代表图像能够识别；字体生成样本的结果也不等于游戏截图或导入流程验收。颜文字专项模型与 emoji 图像识别需要分别评估。

## CPU 资源与接入判定

在本机 Windows 使用 ONNX Runtime CPU、2 个推理线程，执行 3 次独立子进程测量。每次包含模型冷加载、预处理及 48 个裁片推理，合计 990,384 输入像素。最慢一次为 0.134 秒，峰值额外工作集约 15.8 MiB。该数据是专项候选额外计算的本机测量，不是完整 OCR 应用耗时，也不代表其他机器。macOS/MPS 未实机验收。

模型大小与 CPU 预算通过；真实精确改善、普通文字保护、真实负样本以及生产区域和取消链路证据未通过或缺失，最终判定为 `promote: false`。生产新增专项修正为 0。此次不修改 OCR helper、固定模型清单、数据库或预览流程，不增加应用训练依赖。后续若据这些独立结果调整训练或选择区域规则，需要建立新的独立验证资料。
