候选数量增加没有直接转化为最终结果：旧/新开发分别提出 893/773 个新范围，最终保留 446/376 个新候选，实际送识别 51/35 个，融合接受 5/1 个（父框结果落地之前的候选计数，不是正确目标数）。局部归属把完整安全但未识别的目标从旧 27→19、新 29→24，最终却仅旧集增加 1 个、新集零增加，说明仅放通归属仍不足以解决后续损失。

旧开发唯一丢失的正确目标已有确定原因：旧完整候选及其三个视图、分数、决策均未变；同一区域另有一个缺少外侧手臂的新短框也被接受。两个候选均没有基线父框，现有融合只按基线索引记录占用，因而把完整串和短串都追加到结果。此处退化来自**重叠像素区域重复插入**。该失败配置已拒绝，未在冻结后修改源码或补测以覆盖原记录。

## 下一轮改进方案

1. **先解决无父框插入的重复输出。** 为同一区域的像素候选建立互斥归属，比较实际墨迹、完整外侧手臂和上下文；完整旧候选不能因新增内层短框而重复输出。加入完整框/短框、相邻两个独立颜文字、嵌套括号及含正文边界的测试，避免仅靠矩形相交或字符串去重误删独立目标。
2. **将候选范围和安全形状证据一起改进。** 以括号和邻近墨迹组件为锚点，枚举有界的局部完整窗口，减少整段行范围带入正文及截断核心笔画；补齐手臂和弱墨迹的像素归属证据。沿用共享预算、原始像素、正文、邻居、独立形状及多视图守卫，不通过降低阈值换覆盖。重点验证新集 181 个缺少安全完整范围的目标，以及正确原始视图仍无法落地的 19 个目标。
3. **预先声明联合实验和延迟对照。** 单项档用于归因，同时预声明范围与归属的联合档，避免单项不改善时无法观察组合效果。计时采用交错起点与候选、固定重复次数和单一汇总方法，禁止事后选最快轮。旧集 100/30、原有正确零丢失、六项保护零新增、新开发整串改善、p95 增幅不超过 15% 的门槛不变。

这是下一轮待治理与验证的方案，不是已实现或已证明有效的结果。本轮不追加训练或字符级 CTC 定位。新一轮须重新冻结源码与选档依据；两套新保留集只有在开发门禁及双冻结均通过后才能首测，卡片保留集仍须达到 10% 的研究底线。
