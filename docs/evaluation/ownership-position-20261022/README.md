## 裁片与整图差距

同一旧开发集的起点中，244个目标只有66个获得安全完整候选，其中39个有安全完整且已路由的裁片。这39个裁片的专项识别整串正确36个（92.3%）；整图最终目标正确为20/244（8.2%）。这是不同条件和分母的指标，不能把给定裁片的识别率当成整图准确率。

组件档把旧集安全完整覆盖提高到72，但安全路由仍为39，最终正确数仍为20；新集安全路由从35提高到37，最终正确数增加1。当前主要缺口仍是完整候选覆盖，以及候选转为安全路由和最终结果的能力。36个裁片正确与20个最终目标正确的汇总不能直接推出某一种融合原因造成了16个丢失；具体归因仍需逐目标关联证据。

CTC档在旧60场景中只有13个场景得到共14条可靠映射行，新60场景为10个场景、10条行；组件并集模式的映射覆盖相同。CTC位置候选分别为旧集7个、新集4个。大量识别路径的原图变换无法可靠绑定，按预声明回退；轨迹记录的拒绝次数属于事件数，不等于独立行数。当前覆盖不足以支持全面定位改善。没有新增专项父行推理、训练或放宽保护。
