## 裁片与整图差距

同一旧开发集的起点中，244个目标只有66个获得安全完整候选，其中39个有安全完整且已路由的裁片。这39个裁片的专项识别整串正确36个；整图最终目标正确为20/244。并集档把安全完整覆盖提高到81、已路由安全裁片提高到54（整串正确47），但最终目标正确只增加到23。新集同样：起点34个安全路由裁片正确25个，最终21/268；并集43个裁片正确33个，最终19/268。裁片层面的增益大部分没有转化为最终整串正确，并且在新集上伴随3个起点目标丢失。这是不同条件和分母的指标，不能把给定裁片的识别率当成整图准确率，也不能据此推断某一种融合原因。

首轮观察覆盖明显高于上一轮：旧集60个场景、2815条尝试行中2046条得到首轮水平几何绑定，新集2963条中2188条；其余按预声明回退，主要原因为输入变换无法绑定（258/281）、非水平四边形（61/64）、旋转或无效裁切（52/48）、合并父框（42/63）、方向分类（22/29）。首轮CTC位置候选为旧集66个、新集35个，组件位置候选为旧集18个、新集15个。覆盖提升没有转化为整图正确率，当前瓶颈在候选转为安全路由和最终融合的阶段，而非首轮几何本身。没有新增专项父行推理、训练或放宽保护。
