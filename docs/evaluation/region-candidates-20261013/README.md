# 2026-10-13 候选定位改进：记录卡片与真实截图版式的像素分支

[返回 README 评测结果](../../../README.md#评测结果) · [历次版本对比](../../../README.md#历次版本对比)

本轮不训练、不改专项模型（`ppocrv6-tiny-exp-20261013-001`）与分类器（`kaomoji-crop-classifier-exp-20261013-002`），只改研究链路的候选定位规则，GPU 账本上限为 0 秒。起点是 README [两阶段链路落实状态](../../../README.md#两阶段链路落实状态)与[生产/研究链路对照](../chain-comparison-20261013/README.md)记录的逐面归因：卡片开发集 269 面中 133 面的候选切掉手臂或尾缀、123 面的候选混入正文，真实截图像素分支候选为 0。四项规则改动如下。

- 构建物理行前剔除高度超过 72 px 或宽度超过 1024 px 的结构组件（卡片边框、分隔线），沿用既有尺寸上限。4 张真实截图由“整图并成 1 行”变为 10 到 22 行。
- 括号形状对按分块与整行分别检测并去重，墨迹高度基准取被扫描单元局部；卡片开发集括号对候选由 0 变为 118。
- 候选由括号对向外桥接外侧原子，遇“正文样单元”停止：x 范围相距不超过 2 px 的连通域合并为字形单元，高与宽均不小于行高 0.65 倍且墨迹密度不低于 0.4 时视为正文。开发集真值测量：外侧原子单元中满足该判据的仅 2/192（卡片）、1/112（混合），贴合正文首个单元 176/249、12/13 满足。像素分块容器旁无正文样单元时保留并集，首遍框不扩大像素包络。
- 同一首遍区域被多个候选接受时，面积更大的候选替换该区域，较小者记为已消费；视图投票规则不变。
